# Code of Conduct

## Our pledge

Everyone who takes part in `maven-mcp` (issues, pull requests, reviews,
security advisories and any other project space) is welcome regardless of
background, identity or experience. We want a harassment-free, respectful
place to work on the project.

This code of conduct is based on the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Expected behavior

- Be respectful and assume good intent.
- Give and accept constructive, specific feedback.
- Focus on what is best for the project and its users.
- Take responsibility for mistakes and learn from them.
- Respect other people's privacy: do not post someone else's private data,
  credentials or private code.

## Unacceptable behavior

- Harassment, insults, or personal or political attacks.
- Sexualized language or imagery, or unwelcome attention.
- Discriminatory jokes or language.
- Publishing others' private information without explicit permission.
- Deliberately disruptive behavior, such as spam or repeated off-topic posts.
- Other conduct that could reasonably be considered inappropriate in a
  professional setting.

## Scope

This code of conduct applies in every project space on GitHub and when someone
represents the project elsewhere.

## Reporting

The maintainer, István Földházi, is responsible for enforcing this code of
conduct. To report a problem privately, use GitHub's **Report content** menu on
the comment, issue or pull request and choose to report it to the repository
maintainers. You can also report abuse to GitHub directly. Reports are handled
confidentially and on a best-effort basis.

Security vulnerabilities are not conduct reports; follow
[SECURITY.md](SECURITY.md) instead.

## Enforcement

The maintainer may edit, hide or delete comments, close issues or pull
requests, and temporarily or permanently block a participant whose behavior
violates this code of conduct. The response depends on the severity: a private
or public warning, a temporary ban, or a permanent ban for repeated or severe
violations.
